# Logo

Three icon options, each an SVG with a 512 px PNG export.

| File | Idea |
|---|---|
| `converge-icon.svg` | Braces around a tick: configuration that matches its desired state. Used in the README header. |
| `loop-icon.svg` | A loop returning to a fixed point: applying a configuration again changes nothing. |
| `prompt-icon.svg` | A prompt in a hexagon: PowerShell resources. |

`wordmark-banner.svg` is the README header: the first icon and the module name on a dark panel, so
it reads the same in a light or dark theme. `wordmark-light.svg` and `wordmark-dark.svg` are the
same wordmark without the panel, for light and dark backgrounds. `converge-icon-128.png` is a small export for places that need a square
PNG, such as a package icon.

To switch the README to another option, replace the icon group in the wordmark files.
