# Logo

Three icon options, each an SVG with a 512 px PNG export.

| File | Idea |
|---|---|
| `converge-icon.svg` | Braces around a tick: configuration that matches its desired state. Used in the README header. |
| `loop-icon.svg` | A loop returning to a fixed point: applying a configuration again changes nothing. |
| `prompt-icon.svg` | A prompt in a hexagon: PowerShell resources. |

`wordmark-light.svg` and `wordmark-dark.svg` pair the first icon with the module name, for light
and dark backgrounds. `converge-icon-128.png` is a small export for places that need a square
PNG, such as a package icon.

To switch the README to another option, replace the icon group in the two wordmark files.
